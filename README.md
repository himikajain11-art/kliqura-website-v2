# kliqura Digital Website

Premium multi-page React website for kliqura Digital.

## Run locally

1. Open this folder in VS Code or a terminal.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

## Production build

Run `npm run build` to create the production-ready `dist` folder.

## Personalise it

- Brand images: `src/assets/`
- Brand colours and styling: `src/style.css`
- Website content: `src/data/content.js`
- Pages and interactive features: `src/App.jsx`

The WhatsApp link currently uses a generic WhatsApp message link. Replace `WA` near the top of `src/App.jsx` with your WhatsApp number when it is ready.
